## 확인한 사항

- 전체 33개 테스트 파일, 225개 테스트 통과.
- TypeScript 타입 검사, ESLint, Next.js 프로덕션 빌드 통과.
- 배포 URL의 8개 화면 HTTP 200, 비인증 과제 POST 401 확인.
- 공개 브라우저에서 권역·유형 필터, 현장검증 세션 저장 및 보고서 상태 반영 확인. 모바일 390px 화면의 본문 가로 넘침 없음.
- 독립 코드 검토에서 발견한 원천 좌표 `(0,0)` 1개 제외. 권역 내부 집계 37/13/23, 밖 54개.
- 배포 파일에서 로컬 인증키·Vercel 토큰을 제외하는 `.vercelignore` 적용.
- Git 대상 111개 파일에 로컬 인증키·Vercel 토큰 값이 포함되지 않음을 확인.

## 제출 운영

공식 기능설명서 양식으로 작성한 PDF와 공개 URL을 사용한다. 활용 API 체크 항목은 `한국관광공사_국문 관광정보 서비스`와 `한국관광공사_빅데이터_지역별 방문자수`이다. 실제 신청자의 인증키는 제출 사이트 전용 항목에 입력하며 공개 저장소·설명서에는 기록하지 않는다.

이 배포 및 자료 준비는 공모전 접수 완료를 뜻하지 않는다. 제출자는 팀원·과제번호·입력 내용을 확인하고 PDF를 첨부한 뒤 제출 완료 화면을 확인해야 한다.
